# EduFlow — Веб-платформа для преподавателей и учебных центров с Telegram-ботом

**EduFlow** — это минималистичная, быстрая и эстетичная платформа на **React**, разработанная специально для преподавателей курсов, языковых школ, репетиторских центров и учебных заведений.

---

## 🌟 Основные возможности

### 1. 👥 Учет учеников и групп
- **Управление группами**: создание курсов, расписание занятий, цвета групп, учет вместимости.
- **База учеников**: ФИО, телефон, привязка к группе, стоимость обучения, плановая дата и время следующей оплаты.
- **Персональные коды доступа** (например, `ENG-4819`) для мгновенного подключения учеников к Telegram-боту.

### 2. 📚 Массовая рассылка домашних заданий через Telegram-бота
- Преподаватель выбирает группу на сайте, вводит тему урока, задание, дедлайн и ссылки на учебные материалы.
- Нажимает **«Опубликовать и разослать в Telegram»** — бот мгновенно доставляет красивое форматированное сообщение с заданием всем ученикам этой группы.

### 3. 📝 Проверка сданных работ (Вкладка «Проверка ДЗ»)
- Ученики выполняют задания и присылают ответы (текст, фото тетради или файлы) прямо в Telegram-бот.
- Все работы автоматически попадают в специальную вкладку сайта **«Проверка ДЗ»**.
- Преподаватель оценивает работу (например, `5/5` или `95/100`), пишет комментарий с разбором ошибок, и нажимает **«Сохранить и отправить отзыв»**.
- Оценка и комментарий учителя автоматически приходят ученику в Telegram!

### 4. 🔔 Автоматические напоминания об оплате за 1 день
- При регистрации ученика указывается сумма оплаты, плановая дата и время платежа.
- **Фоновый планировщик:** ровно **за 1 день (24 часа)** до срока бот автоматически отправляет ученику вежливое персональное уведомление с указанием суммы, группы и срока.
- Также доступна кнопка ручной отправки напоминания в один клик.

### 5. ✅ Фиксация оплаты и продление периода
- Когда ученик оплачивает обучение, учитель нажимает кнопку **«Оплатил»** на карточке ученика.
- Система фиксирует транзакцию, отправляет ученику квитанцию в Telegram-бот и автоматически сдвигает дату следующего платежа на +1 месяц.

### 6. 💰 Финансовая аналитика и автоматический расчет доходов
- **Всего за всё время:** точный расчет всех полученных платежей за всю историю.
- **За прошедший месяц:** отдельный блок с суммой дохода за прошлый календарный месяц.
- **За текущий месяц:** сумма поступивших оплат в текущем месяце.
- **Ожидаемый сбор:** прогноз общего дохода на основе стоимости обучения активных учеников.
- **Наглядные графики:** динамика поступлений за последние 6 месяцев.

### 7. 🤖 Интерактивный Telegram-симулятор
- Встроенный виртуальный смартфон ученика прямо в интерфейсе!
- Позволяет протестировать весь цикл (рассылка ДЗ, получение напоминаний, отправка решения в бот и получение оценки) прямо на экране без необходимости создавать реального бота.
- Подключение реального Telegram-бота выполняется в один клик вставкой токена от `@BotFather`.

## 🚀 Как запустить

### Быстрый запуск (Windows):
Просто дважды кликните по файлу **`start.bat`**.

Сервер автоматически запустится, и откроется ваш браузер по адресу:
👉 **http://localhost:3000**

## 🛠 Технический стек
- **Frontend:** React 18, Tailwind CSS, Heroicons / Crisp SVG Icons.
- **Backend:** Node.js (высокопроизводительный сервер, нативный HTTP, SQLite WAL).
- **База данных:** SQLite (`data/database.sqlite`) с автоматической инициализацией и структурой для групп, учеников, платежей, ДЗ и логов.
- **Telegram Bot API:** Нативная интеграция (Long Polling + Webhook Ready).
